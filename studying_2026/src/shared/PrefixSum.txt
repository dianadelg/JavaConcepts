Prefix Sum Walkthrough

A prefix sum is always everything from the beginning through one index, so subtracting an earlier prefix from a later prefix leaves the continuous section between them.

So [ 1 2 1 2] -- prefix sums [0, 1, 3, 4, 6]
- zero is before reading anything
0 = []
1 = [1]
3 = [1, 2]
4 = [1, 2, 1]
6 = [1, 2, 1, 2]



/*
 * PREFIX SUM + HASHMAP
 * FULL WALKTHROUGH
 *
 * Problem:
 *
 * nums = [1, 2, 1, 2]
 * k = 3
 *
 * Goal:
 *
 * Count how many continuous subarrays have a sum of 3.
 *
 * -------------------------------------------------------
 * KEY EQUATION
 * -------------------------------------------------------
 *
 * currentPrefixSum - earlierPrefixSum = k
 *
 * Rearranged:
 *
 * earlierPrefixSum = currentPrefixSum - k
 *
 * So at every number, ask:
 *
 * "Have I seen currentPrefixSum - k before?"
 *
 * IMPORTANT:
 *
 * A prefix sum is ALWAYS continuous.
 *
 * It means:
 *
 * the sum of every element from index 0
 * through some earlier index.
 *
 * Example:
 *
 * nums = [1, 2, 1, 2]
 *
 * Prefix sums:
 *
 * 0 = before the array
 * 1 = [1]
 * 3 = [1, 2]
 * 4 = [1, 2, 1]
 * 6 = [1, 2, 1, 2]
 *
 * A prefix sum can never represent a non-continuous
 * group such as [1, 1].
 *
 * Why subtraction creates a continuous subarray:
 *
 * larger prefix - earlier prefix
 * =
 * the continuous section between those checkpoints
 *
 * Example:
 *
 * [1, 2, 1] - [1] = [2, 1]
 *
 * We are not subtracting a random value.
 *
 * We are removing the entire earlier prefix.
 *
 * -------------------------------------------------------
 * START
 * -------------------------------------------------------
 *
 * prefixCounts = {0=1}
 * currentSum = 0
 * count = 0
 *
 * Why store 0 -> 1?
 *
 * It represents the checkpoint before the array begins.
 *
 * This lets us detect subarrays that begin at index 0.
 *
 * -------------------------------------------------------
 * READ 1
 * -------------------------------------------------------
 *
 * currentSum = 1
 *
 * needed = currentSum - k
 * needed = 1 - 3
 * needed = -2
 *
 * Ask:
 *
 * "Have we seen a prefix sum of -2?"
 *
 * No.
 *
 * So no valid subarray ends here.
 *
 * Store the current prefix sum:
 *
 * prefixCounts = {0=1, 1=1}
 * count = 0
 *
 * -------------------------------------------------------
 * READ 2
 * -------------------------------------------------------
 *
 * currentSum = 3
 *
 * needed = currentSum - k
 * needed = 3 - 3
 * needed = 0
 *
 * Ask:
 *
 * "Have we seen a prefix sum of 0?"
 *
 * Yes, once.
 *
 * The prefix sum 0 is the checkpoint before the array.
 *
 * So:
 *
 * current prefix - earlier prefix = k
 *
 * 3 - 0 = 3
 *
 * The valid subarray is:
 *
 * [1, 2]
 *
 * indexes 0 through 1
 *
 * Increase count:
 *
 * count = 1
 *
 * Store the current prefix sum:
 *
 * prefixCounts = {0=1, 1=1, 3=1}
 *
 * -------------------------------------------------------
 * READ THE NEXT 1
 * -------------------------------------------------------
 *
 * currentSum = 4
 *
 * needed = currentSum - k
 * needed = 4 - 3
 * needed = 1
 *
 * Ask:
 *
 * "Have we seen a prefix sum of 1?"
 *
 * Yes, once.
 *
 * The earlier prefix sum 1 came from:
 *
 * [1]
 *
 * The current prefix sum 4 came from:
 *
 * [1, 2, 1]
 *
 * Remove the earlier prefix:
 *
 * [1, 2, 1] - [1] = [2, 1]
 *
 * Or using sums:
 *
 * 4 - 1 = 3
 *
 * The valid subarray is:
 *
 * [2, 1]
 *
 * indexes 1 through 2
 *
 * Increase count:
 *
 * count = 2
 *
 * Store the current prefix sum:
 *
 * prefixCounts = {0=1, 1=1, 3=1, 4=1}
 *
 * -------------------------------------------------------
 * READ THE FINAL 2
 * -------------------------------------------------------
 *
 * currentSum = 6
 *
 * needed = currentSum - k
 * needed = 6 - 3
 * needed = 3
 *
 * Ask:
 *
 * "Have we seen a prefix sum of 3?"
 *
 * Yes, once.
 *
 * The earlier prefix sum 3 came from:
 *
 * [1, 2]
 *
 * The current prefix sum 6 came from:
 *
 * [1, 2, 1, 2]
 *
 * Remove the earlier prefix:
 *
 * [1, 2, 1, 2] - [1, 2] = [1, 2]
 *
 * Or using sums:
 *
 * 6 - 3 = 3
 *
 * The valid subarray is:
 *
 * [1, 2]
 *
 * indexes 2 through 3
 *
 * Increase count:
 *
 * count = 3
 *
 * Store the current prefix sum:
 *
 * prefixCounts = {0=1, 1=1, 3=1, 4=1, 6=1}
 *
 * -------------------------------------------------------
 * FINAL ANSWER
 * -------------------------------------------------------
 *
 * Valid subarrays:
 *
 * [1, 2]  indexes 0-1
 * [2, 1]  indexes 1-2
 * [1, 2]  indexes 2-3
 *
 * Return:
 *
 * 3
 *
 * -------------------------------------------------------
 * MEMORY TRICK
 * -------------------------------------------------------
 *
 * currentPrefixSum = everything from the beginning through now
 *
 * earlierPrefixSum = everything from the beginning through
 * an earlier checkpoint
 *
 * Subtracting them removes the earlier beginning section.
 *
 * What remains is the continuous section between them.
 *
 * currentPrefixSum - earlierPrefixSum = subarray sum
 *
 * Therefore:
 *
 * Have I seen currentPrefixSum - k before?
 */
 
 
 /*
 * -------------------------------------------------------
 * WHAT IS STORED IN THE HASHMAP?
 * -------------------------------------------------------
 *
 * The HashMap does NOT store the original array.
 *
 * It does NOT store subarrays.
 *
 * It does NOT store indexes.
 *
 * It stores:
 *
 *     key   = prefix sum
 *     value = how many times we've seen that prefix sum
 *
 * Think of it as:
 *
 * "What running totals have I reached so far?"
 *
 * -------------------------------------------------------
 * Example
 * -------------------------------------------------------
 *
 * nums = [1, 2, 1, 2]
 *
 * Prefix sums:
 *
 * 0 = before reading anything
 * 1 = [1]
 * 3 = [1, 2]
 * 4 = [1, 2, 1]
 * 6 = [1, 2, 1, 2]
 *
 * Prefix Sum Array:
 *
 * [0, 1, 3, 4, 6]
 *
 * As we iterate, the HashMap is built one prefix sum at a time.
 *
 * -------------------------------------------------------
 * Before reading anything
 * -------------------------------------------------------
 *
 * currentSum = 0
 *
 * HashMap:
 *
 * {
 *     0 : 1
 * }
 *
 * Meaning:
 *
 * "I've seen a running total of 0 one time."
 *
 * -------------------------------------------------------
 * Read 1
 * -------------------------------------------------------
 *
 * currentSum = 1
 *
 * Store it:
 *
 * {
 *     0 : 1,
 *     1 : 1
 * }
 *
 * Meaning:
 *
 * I've seen:
 *
 * prefix sum 0 once
 * prefix sum 1 once
 *
 * -------------------------------------------------------
 * Read 2
 * -------------------------------------------------------
 *
 * currentSum = 3
 *
 * Store it:
 *
 * {
 *     0 : 1,
 *     1 : 1,
 *     3 : 1
 * }
 *
 * -------------------------------------------------------
 * Read next 1
 * -------------------------------------------------------
 *
 * currentSum = 4
 *
 * Store it:
 *
 * {
 *     0 : 1,
 *     1 : 1,
 *     3 : 1,
 *     4 : 1
 * }
 *
 * -------------------------------------------------------
 * Read final 2
 * -------------------------------------------------------
 *
 * currentSum = 6
 *
 * Store it:
 *
 * {
 *     0 : 1,
 *     1 : 1,
 *     3 : 1,
 *     4 : 1,
 *     6 : 1
 * }
 *
 * Notice something?
 *
 * The HashMap keys are simply the prefix sums we've
 * encountered so far.
 *
 * Prefix Sum Array:
 *
 * [0, 1, 3, 4, 6]
 *
 * HashMap Keys:
 *
 * {
 *     0,
 *     1,
 *     3,
 *     4,
 *     6
 * }
 *
 * The HashMap is just a FAST lookup table that answers:
 *
 * "Have I seen this prefix sum before?"
 *
 * -------------------------------------------------------
 * WHY IS THE VALUE AN INTEGER?
 * -------------------------------------------------------
 *
 * Because the same prefix sum can occur multiple times.
 *
 * Example:
 *
 * nums = [1, -1, 1, -1]
 *
 * Prefix sums:
 *
 * [0, 1, 0, 1, 0]
 *
 * HashMap:
 *
 * {
 *     0 : 3,
 *     1 : 2
 * }
 *
 * Meaning:
 *
 * We've seen:
 *
 * running total 0 three times
 * running total 1 two times
 *
 * This matters because every earlier occurrence represents
 * another possible starting checkpoint for a valid subarray.
 *
 * So if currentSum - k = 0 and:
 *
 *     0 : 3
 *
 * then THREE different subarrays ending at the current
 * position have sum = k.
 *
 * That's why we store COUNTS instead of just true/false.
 */
